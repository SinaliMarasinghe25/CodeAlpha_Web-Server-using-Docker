About This Project

Docker containerization — CodeAlpha DevOps Internship Task

🎯 What I Built

A production-grade Nginx web server running inside a Docker container, covering the full container lifecycle from image build to health monitoring.

🐳 What is Docker?

Docker packages applications and all their dependencies into lightweight, portable containers that run identically on any machine.

❌ Without Docker

  • "Works on my machine" problem
  • Manual dependency setup
  • Hard to scale
  • Environment conflicts

✅ With Docker

  • Runs identically everywhere
  • Everything bundled together
  • Scale with one command
  • Complete isolation
